# StructuredMerge 0.2.1 (release candidate)

This is a pre-publication release note for the lockstep kernel and generated
binding closure. It is not a publication authorization and does not claim that
registry or hosted-runner gates have passed.

## Included

- Canonical `smorg` CLI with the retained `smorg-rs` compatibility executable.
- Typed Ruby/Python binding artifacts and checked API baselines.
- Deterministic six-platform CLI archives with SHA-256 asset inventory,
  Homebrew/Scoop manifests and provenance/partial-publication evidence.
- Installed Python artifact and typed benchmark gates against the checked-in
  generated binding.

## Verified locally

- Workspace Rust tests and package metadata validation.
- CLI discovery, conflict-review, installed real-Git and archive smoke gates.
- Python artifact, generated test-app and typed benchmark gates.
- Reproducible wheel and archive builds when `SOURCE_DATE_EPOCH` is bound to
  the reviewed source revision.

## Before publication

- Re-run Alef generation after the updated Alef and TSLP releases are available;
  verify generated bytes and all dependent artifacts again.
- Execute the hosted six-platform matrix and inspect its assembled evidence
  artifact.
- Publish the dependency closure in order, then run registry-mode installs and
  consumer gates. Publication remains explicitly unauthorized until those gates
  and maintainer approval are complete.
- Keep parser candidates (`ruby-prism`, `oxc_parser`, `swc_ecma_parser`,
  `saphyr`, `taplo`, `comrak`) out of defaults until their recorded
  golden-master and benchmark evidence exists.
